# 屿光 · 一座岛的慢时光

一个小清新风格的交互式 3D 海岛场景。使用 Three.js 实时渲染，所有脚本与素材均内置于单个 HTML 文件，不需要安装依赖。

## 浏览

打开仓库对应的 GitHub Pages 网站；或下载 `index.html` 后使用支持 WebGL 的现代浏览器打开。

## 交互

- 鼠标拖动：环绕小岛；滚轮：缩放。
- 点击木门、烟囱和小船，或点击对应的小圆点：触发互动。
- 时间轴和日出、晴昼、日落、星夜按钮：调整光照与时段。
- 右上角开启合成海浪环境音、沉浸模式与互动指南。
- 空格：暂停或继续时间；R：重置视角；H：切换沉浸模式。
- 触摸屏支持拖动与双指缩放。

Three.js r147 的 MIT 许可证声明保留在 HTML 的内嵌库中。
